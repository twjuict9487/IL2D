# 緣緣莊

與黍互動可進入緣緣莊。第一張農場地圖南側是購物區；靠近祀並按 `E` 或 `F`，可用祀幣購買種子、擴充農地，用主貨幣購買米或麥食材（每包 10 份），或請她開始營業。東側入口通往 24×24 的自動農田。

請祀開店後會進入南側餐廳。餐廳有八張餐桌與三個爐台；靠近爐台按 `E`，用 `W／S` 和 `Enter` 切換菜色、加入最多三道菜的佇列。祀會依移動、工作與冷卻時間送餐、清桌。農地會在遊戲進行時自動種植、收成與補種。

營業時間為 180 秒。關門時未完成的訂單取消且不付款，已消耗的食材不退還。結算畫面會顯示訂單數、收入與祀幣餘額。若在營業中存檔後讀取，該場營業依相同規則取消；祀幣、種子、食材、農地進度與廚師指定菜色仍會保留。

三張地圖的背景音樂由各自的 `music_override` 指向專案內既有的 Yuanyuan's Blazing Stoves 音檔。內部地圖 ID 與舊 Farmer Mod 存檔欄位保留，以維持舊資料相容。
